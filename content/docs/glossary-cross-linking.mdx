# Glossary Cross-Linking

CryptoViz features an automated **Glossary Cross-Linking Engine** that scans documentation text for key cryptographic concepts and turns them into interactive, accessible term tooltips.

## Features

1. **Automatic Term Detection**: Automatically detects 25+ core cryptography terms (such as *Caesar Cipher*, *RSA Cryptosystem*, *SHA-256*, *Initialization Vector*, *Nonce*, *Key Derivation Function*, etc.) without breaking word boundaries or markup formatting.
2. **Interactive Definition Tooltips**: Hovering or focusing (`Tab`) on highlighted terms opens a popover card displaying a summary, category badge, mathematical formula, and direct links to the relevant visualizers.
3. **Glossary Explorer (`/glossary`)**: Full-page A-Z searchable glossary featuring category filters, alphabet jump links, and detailed term definitions.
4. **Accessibility (WCAG 2.1 AA)**: Built with proper ARIA roles (`aria-expanded`, `aria-haspopup="dialog"`), full keyboard navigation, high contrast colors, and zero accessibility violations.
